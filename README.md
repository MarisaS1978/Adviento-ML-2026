# 🇦🇷 Español

## 🎯 Sobre el proyecto

**Adviento ML 2026** es una experiencia educativa e interactiva inspirada en los tradicionales calendarios de Adviento.

Durante 24 días, propone descubrir conceptos, herramientas y técnicas de Machine Learning a través de contenidos progresivos, ejemplos en Python y pequeños desafíos prácticos.

El objetivo es acercar el aprendizaje del Machine Learning de una manera visual, dinámica y accesible, combinando teoría y práctica.

## 🎄 ¿Qué vas a encontrar?

- 24 jornadas de aprendizaje.
- Contenidos organizados de menor a mayor dificultad.
- Conceptos fundamentales de Machine Learning.
- Ejemplos prácticos utilizando Python.
- Introducción a las principales librerías de Data Science.
- Ejercicios y desafíos para poner en práctica lo aprendido.
- Un recorrido final de integración de conocimientos.

## 🐍 Herramientas y tecnologías de aprendizaje

El recorrido aborda herramientas habituales del ecosistema Python y Data Science:

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

## 🧠 Objetivos de aprendizaje

Al finalizar el recorrido, se busca que los participantes puedan:

- Comprender los principales conceptos de Machine Learning.
- Explorar, limpiar y preparar conjuntos de datos.
- Identificar variables relevantes para un modelo.
- Entrenar modelos básicos de regresión y clasificación.
- Comprender algoritmos de clustering.
- Interpretar métricas de evaluación.
- Reconocer problemas de overfitting y underfitting.
- Aplicar técnicas de validación y optimización.
- Comprender las etapas de un proyecto de Machine Learning.

# 🤖 ML Advent Calendar 2026
### 24 Days to Discover and Learn Machine Learning

**An interactive learning journey through Machine Learning, from fundamental concepts to building and evaluating predictive models.**

🌐 **Live Application:** [Try ML Advent Calendar 2026](https://advientoml2026.netlify.app/)

## 🎯 About the Project

**ML Advent Calendar 2026** is an interactive educational experience inspired by traditional Advent calendars.

Over 24 days, users can explore Machine Learning concepts, tools and techniques through progressive lessons, Python examples and practical challenges.

The goal is to make Machine Learning learning more accessible and engaging by combining theoretical explanations with hands-on practice.

## 🎄 What Does It Include?

- 24 days of learning.
- Progressive educational content.
- Fundamental Machine Learning concepts.
- Practical Python examples.
- Introduction to Data Science libraries.
- Exercises and learning challenges.
- A final project integrating the concepts covered.

| Day | Topic |
|---:|---|

| 02 | Types of Learning: Supervised, Unsupervised and Reinforcement Learning |

## 🐍 Learning Tools and Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook

## 🧠 Learning Objectives

By completing the calendar, learners will be introduced to how to:

- Understand core Machine Learning concepts.
- Explore, clean and prepare datasets.
- Identify relevant features.
- Train basic regression and classification models.
- Understand clustering algorithms.
- Interpret model evaluation metrics.
- Identify overfitting and underfitting.
- Apply validation and optimization techniques.
- Understand the stages of a Machine Learning project.
